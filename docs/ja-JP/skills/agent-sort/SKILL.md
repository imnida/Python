# エージェントソートスキル

様々なデータ構造とアルゴリズムを使用してデータを効率的にソートするスキルです。

## 概要

ファイル、データベースレコード、APIレスポンスなど、様々なデータソースを高速にソートします。

## 機能

- **スマートソート**: データタイプに応じた最適なアルゴリズムを選択
- **マルチキー**: 複数のフィールドでの複合ソート
- **ストリーミング**: 大規模データセットのストリーミングソート
- **カスタム比較**: ユーザー定義の比較関数をサポート

## 使い方

```bash
/sort data.json --key name                    # 名前でソート
/sort data.csv --key age,name --desc          # 年齢降順、名前昇順
/sort --stdin --key timestamp                 # 標準入力からソート
```

## 対応フォーマット

- JSON配列
- CSV/TSV
- JSONL (JSON Lines)
- 標準入力ストリーム
